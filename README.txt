EMT Field Pro — PWA package

Files are ready for any static HTTPS host (GitHub Pages, Cloudflare Pages, Netlify, etc.).

Install on iPhone after hosting:
1. Open the HTTPS site in Safari once while online.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on Open as Web App if shown, then Add.
5. Launch EMT Field Pro once while online so its offline cache is populated.
6. It can then run offline from the Home Screen.

Important field note:
The app uses common default bender presets and geometric calculations. Verify take-up/reference marks on your actual bender and make a test bend for critical dimensions.
